## Description

🧹 Quick Clean — 한 번의 클릭으로 브라우저 정리

개인정보 보호의 주도권을 되찾으세요. Quick Clean은 탭을 벗어나지 않고 탐색 데이터를 즉시 삭제합니다.

━━━━━━━━━━━━━━━━━━━━━━

✅ Quick Clean이 하는 일:

• 방문 기록 — 흔적을 순식간에 지우세요
• 쿠키 — 허용 목록으로 즐겨 찾는 사이트를 보호하며 쿠키를 삭제
• 캐시 — 공간을 확보하고 페이지를 새로 불러오도록 강제
• 양식 데이터 — 자동 완성 항목 제거
• 다운로드 — 다운로드 기록 삭제
• 저장된 비밀번호 — 필요할 때 삭제
• 로컬 저장소 — localStorage와 IndexedDB 삭제
• 탭 — 열려 있는 모든 탭을 한 번에 닫기

━━━━━━━━━━━━━━━━━━━━━━

⚡ 주요 기능:

🌐 현재 사이트만 정리 — 다른 항목은 건드리지 않고 현재 사이트의 쿠키, 데이터, 방문 기록만 삭제
📊 로컬 통계 — 정리한 횟수, 사이트 수, 방문 기록 수 확인(기기에만 저장)
🌗 라이트 및 다크 테마 — 시스템에 맞추거나 직접 선택
🌍 14개 언어 — English, Français, Español, Português (Brasil · Portugal), Deutsch, Italiano, Русский, Türkçe, العربية, हिन्दी, 中文, 日本語, 한국어, Bahasa Indonesia. 브라우저 언어에 따라 인터페이스가 표시됩니다
🕐 유연한 기간 설정 — 1시간, 24시간, 7일 또는 전체
🛡️ 허용 목록 — 중요한 사이트(은행, 이메일 등)의 쿠키 보호
⌨️ 키보드 단축키 — 팝업을 열지 않고 Ctrl+Shift+E로 정리
🔔 알림 — 정리할 때마다 시각적으로 확인
🚀 시작 시 정리 — Chrome 실행 시 자동으로 정리하는 옵션
🎨 깔끔한 인터페이스 — 현대적이고 빠르며 직관적인 디자인
