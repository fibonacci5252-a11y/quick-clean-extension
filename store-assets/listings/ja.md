Chrome Web Store language: Japanese

## Name
Quick Clean

## Summary (taken from the manifest, max 132 characters)
ワンクリックで閲覧データを削除：履歴、Cookie、キャッシュなど。

## Description

🧹 Quick Clean — ワンクリックでブラウザをきれいに

プライバシーを取り戻しましょう。Quick Clean は、タブを離れることなく閲覧データをすぐに削除します。

━━━━━━━━━━━━━━━━━━━━━━

✅ Quick Clean でできること：

• 閲覧履歴 — 痕跡を一瞬で消去
• Cookie — 許可リストでお気に入りのサイトを守りながら Cookie を削除
• キャッシュ — 容量を空け、ページを最新の状態で再読み込み
• フォームデータ — 自動入力の候補を削除
• ダウンロード — ダウンロード履歴を消去
• 保存済みパスワード — 必要なときに削除
• ローカルストレージ — localStorage と IndexedDB を消去
• タブ — 開いているすべてのタブをワンクリックで閉じる

━━━━━━━━━━━━━━━━━━━━━━

⚡ 主な機能：

🌐 このサイトだけ消去 — 現在のサイトの Cookie、データ、履歴だけを、ほかには触れずに削除
📊 ローカル統計 — 消去した回数、サイト数、履歴の件数を確認（データはお使いのデバイスにのみ保存）
🌗 ライト／ダークテーマ — システムに合わせるか、お好みで選択
🌍 14 言語対応 — English, Français, Español, Português, Deutsch, Italiano, Русский, Türkçe, العربية, हिन्दी, 中文, 日本語, 한국어, Bahasa Indonesia。表示言語はブラウザの言語に従います
🕐 柔軟な期間指定 — 1時間、24時間、7日間、またはすべて
🛡️ 許可リスト — 重要なサイト（銀行、メールなど）の Cookie を保護
⌨️ キーボードショートカット — ポップアップを開かずに Ctrl+Shift+E で消去
🔔 通知 — 消去のたびに視覚的に確認
🚀 起動時に消去 — Chrome の起動時に自動で消去するオプション
🎨 すっきりした画面 — モダンで高速、直感的なデザイン

━━━━━━━━━━━━━━━━━━━━━━

• データの収集も送信も一切なし
• トラッキングや分析なし
• 100% ローカルで動作
• 透明性のあるソースコード
